## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI_With_Pratyush.git
cd AI_With_Pratyush
```

### 2. Set up the Python environment

Install [UV](https://docs.astral.sh/uv/) if you haven't already.

```bash
uv sync
```

### 3. Configure environment variables

Create a `.env` file in the relevant project directory and add your API key:

```env
GROQ_API_KEY=your_api_key_here
```

Never commit API keys or other sensitive credentials to GitHub.

### 4. Run the first LLM implementation

```bash
cd Week1/day1
python hello_llm.py
```
